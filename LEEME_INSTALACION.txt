STOCK+ - EXCLUSION DE PRODUCTOS OBSOLETOS EN COMPRAS Y CONTROL DE STOCK

INSTALACION
1. Haz una copia de seguridad de tu proyecto antes de sustituir archivos.
2. Descomprime este ZIP EN LA RAIZ de proyectoStockReact, conservando las carpetas.
3. Sobrescribe los archivos coincidentes y reinicia backend y frontend.
4. No es necesaria ninguna modificacion de tablas ni del archivo .env.

CAMBIO FUNCIONAL
- La consulta /api/stock/control-stock descarta los registros de productos con
  TRIM(UPPER(obsoleto)) = 'S'. Valores N, vacios o NULL siguen incluidos.
- Los filtros de familias y proveedores dejan de incluir valores asociados
  exclusivamente a productos obsoletos.
- Las propuestas de compra guardadas localmente se comprueban contra PostgreSQL
  y se depuran antes de mostrarlas o exportarlas a CSV.
- La validacion de propuestas usa un endpoint autenticado, protegido por los
  permisos de Compras y control de stock.
- Si no se puede validar un borrador guardado, no se muestra ni se exporta:
  permanece en el almacenamiento local para volver a comprobarlo despues.

COMPROBACIONES
- Node --check de 125 ficheros .js: sin errores.
- Dos ficheros React JSX modificados: sintaxis valida (parser TypeScript).
- 5 pruebas de regresion pasan. SQL generado tambien revisado con
  simulacion de consultas; sin conexion real a PostgreSQL.
- Pendiente de validar en la instalacion real con Node 24 y PostgreSQL.

NO SE MODIFICAN OTRAS PANTALLAS DE PRODUCTOS (STOCK GENERAL, TARIFAS,
CATALOGOS Y RESERVAS). EL CAMBIO SOLO AFECTA A COMPRAS/CONTROL DE STOCK.

ESTE ZIP SOLO CONTIENE LOS CAMBIOS NUEVOS DE CONTROL DE STOCK.
